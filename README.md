# Hans Dhika Portfolio

Simple multi-page GitHub Pages portfolio.

Pages:
- Home
- Tools
- MML Parser
- Projects
- About
- Contact

The MML Parser works client-side: the uploaded TXT/LOG file is processed in the browser and can be exported as CSV.

Before publishing, replace the placeholder LinkedIn, Instagram, WhatsApp, and email links in `contact/index.html`.

## Test locally

You can simply extract the ZIP and double-click `index.html`.
The CSS and JavaScript paths are relative, so the multi-page site works both from a local folder and on GitHub Pages.

## Hybrid layout
The homepage contains direct clickable tool cards. The navbar remains available as a shortcut. Contact uses icon-only links with hover colors and tooltips.
