# Huawei MML Script Creator

Web-based Huawei MML command generator for GitHub Pages.

## V1

Currently supports:

- `MOD EUTRANINTRAFREQNCELL`
- Parameter validation
- MML generation
- Copy to clipboard
- Save TXT

## Deploy

Place the `mml-creator` folder in the GitHub Pages repository:

```text
hansdhika.github.io/
└── mml-creator/
```

Then open:

`https://hansdhika.github.io/mml-creator/`

## Data source

Parameter definitions for V1 are based on the supplied Huawei command reference.
