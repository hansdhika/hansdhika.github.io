▣ UE-01 vs All TRP

Estimated signal is a qualitative planning indicator, not real RSRP/RSRQ. For the selected UE, it considers three geometry factors: distance relative to Beam Reach, horizontal offset (H Δ), and vertical offset (V Δ) against the scenario V 3-dB beamwidth. No dBm value is implied.
