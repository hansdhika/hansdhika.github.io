5G NR PCI Conflict Analyzer

Analyze NRCELLPCICONFLICT → calculate Source/Target distance → identify the farthest relation → generate RMV NRCELLRELATION command.

Huawei NR • GitHub Pages • Excel-Compatible Distance

How To

1
Get conflict dataFrom DSP NRCELLPCICONFLICT, identify the affected gNodeB / target relations.
2
Prepare coordinatesEnter Source and Target longitude/latitude. Distance uses the same Spherical Law of Cosines formula as the Excel workbook.
3
Find the farthest relationThe table is sorted by distance descending. The farthest row is the recommended candidate for review; it is not automatically approved for removal.
4
Generate the MMLFill MCC, MNC, Source NRCELLID and Target CELLID, then copy the generated command.

Relation Input

Distance is calculated in kilometers internally. The original how-to slide labels the column “Distance (m)”, while its sample values (24.5493, 0.99885, 0.97902) correspond approximately to km, not meters.
